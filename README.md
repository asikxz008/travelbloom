# TravelBloom

Учебное приложение для рекомендаций по путешествиям. HTML, CSS и JavaScript без зависимостей и сборки.

- Репозиторий: https://github.com/asikxz008/travelbloom
- Сайт: https://asikxz008.github.io/travelbloom/

## Возможности

- Главная страница с введением, фотографией Бали и выбором категории.
- Страница «О нас» с описанием проекта и тремя примерами участников команды с ролями.
- Страница «Контакты» с обязательными полями имени, email и сообщения.
- Навигация с точными подписями задания: `Home`, `About Us`, `Contact Us`, поле поиска, `Search`, `Clear`; мобильное меню.
- Поиск по JSON, без учёта регистра, с поддержкой русских и английских запросов.
- Рекомендации пляжей: Бора-Бора и Бондай (две фотографии).
- Рекомендации храмов: Ангкор-Ват и Кинкаку-дзи (две фотографии).
- Поиск `country` показывает две разные страны: Австралию и Японию, с двумя фотографиями.
- По названию страны можно посмотреть её города: Австралия — Сидней и Мельбурн; Япония — Киото.
- Подробное описание направления в модальном окне; ссылка на Google Maps.
- Сообщения при пустом запросе, отсутствии результатов и ошибке загрузки.
- Адаптивная вёрстка, подписи полей, альтернативные тексты изображений, доступность с клавиатуры.

## Примеры поиска

| Категория | Запросы |
| --- | --- |
| Пляжи | `beach`, `beaches`, `пляж`, `пляжи` |
| Храмы | `temple`, `temples`, `храм`, `храмы` |
| Страны | `country`, `countries`, `страна`, `страны` |
| Название страны | `Australia`, `Австралия`, `Japan`, `Япония` |
| Места | `Sydney`, `Сидней`, `Melbourne`, `Мельбурн`, `Angkor`, `Киото`, `Bondi`, `Bora Bora` |

Форма контактов — демонстрация клиентской валидации и предварительного просмотра сообщения. Она не отправляет email, не сохраняет данные на сервере и не заявляет об успешной отправке. Для реальной отправки потребуется отдельный сервер или сервис форм.

## Запуск локально

Из папки проекта выполните:

```bash
python -m http.server 8080
```

Откройте http://localhost:8080/. Нужен HTTP-сервер: загрузка JSON через `fetch` может не работать при открытии HTML через `file://`.

## GitHub Pages

В настройках репозитория: **Settings → Pages → Deploy from a branch → main → /(root) → Save**. Все ресурсы имеют относительные пути, поэтому сайт работает в подпапке репозитория. Файл `.nojekyll` отключает обработку Jekyll.

## Структура

- `index.html`, `about.html`, `contact.html`: три страницы.
- `styles.css`: стили и адаптивная вёрстка.
- `app.js`: навигация, поиск, карточки, модальное окно и форма.
- `travel_recommendation_api.json`: данные рекомендаций.
- `*.jpg`: фотографии, сохранённые в проекте.
- `favicon.svg`: значок проекта.
